# 볼트 지침 (시험용 — 가상의 내용)

이 볼트는 PARA 구조를 따른다. 정리할 때는 아래 규칙을 지킨다.

## 폴더 구조

```
Vault/
├── _Inbox/ ← 빠른 캡처
├── _workspace/ ← AI 작업 공간 (정리 대상)
├── 1-Projects/ ← 마감·목표가 있는 활성 작업
│   ├── 정산-설계/ ← Phase 0 설계 정본 (동결, 참조용)
│   │   ├── 의사결정/ADR-XXX_제목.md
│   └── {프로젝트명}/
│       ├── PROGRESS.md
│       └── _workspace/ ← 프로젝트 초안
├── 2-Areas/ ← 지속 관리 영역
│   └── {프로젝트명}/
│       ├── 프로젝트_요약.md
│       ├── 의사결정/ADR-XXX_제목.md
│       ├── 기술노트/TN-XXX_제목.md
│       └── 운영/ ← SQL조사·가이드
├── 3-Resources/ ← 참고 자료
│   └── {주제별 폴더}/
├── 4-Archive/ ← 끝난 일
├── _ref/ ← 원본 자료 (읽기 전용)
└── _Templates/
```

## ADR 작성 규칙

**파일명**: `ADR-XXX_핵심결정_한줄요약.md`
**위치**: `2-Areas/{프로젝트명}/의사결정/`

새 ADR이 생성될 때마다 `2-Areas/{프로젝트}/프로젝트_요약.md`의 "주요 의사결정 목록" 테이블 업데이트

## TN 작성 규칙

**파일명**: `TN-NNN_주제.md`
**위치**: `2-Areas/{프로젝트명}/기술노트/`
